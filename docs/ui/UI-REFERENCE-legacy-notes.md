## 0. 证据强度分级

全文每个结论都带一个等级，读的时候先看等级再看结论。

| 等级 | 含义 | 判据 |
|---|---|---|
| **A · 眼见** | 截图里字面可见 | 文字能逐字读出、控件形状与位置能圈出来 |
| **B · 像素测得** | 截图里量出来的 | 用 Pillow 逐行/逐列扫像素得到的边界、颜色值、间距；同一数字有 ±1px 的取整误差 |
| **C · 推断** | 由 A/B 合理推出，**未见** | 标准 Web 控件的默认行为、旧版路由名与按钮语义的对应 |
| **D · 未取证** | 截图里根本没有 | 被窗口/屏幕边缘截断，或该页面/该浮层根本没被拍到 |

**反向证据（必须一起读）**：

1. **旧版 exe 的 Tauri 2 前端是加密内嵌资产，解不开**；后端 5173 已断开（截图顶部与右栏的 `Failed to fetch` 就是它），**无法把界面切到其它页面/状态再补拍**。
2. 仓库内现存的 `frontend-vue/src/**/*.rs`（Leptos 版，61 文件 11,551 行）**晚于**这张截图：配置页已是折叠卡片、顶栏已有四个导航页签与主题切换、投递列表已改成三列卡片网格。**旧版截图与 Leptos 版不是同一个东西**，凡「现有资产已偏离截图」的地方，本文件只标注偏离，不据此改写截图结论。
